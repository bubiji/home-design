## 1. 硬件与 SDK 前提

- 编程接口是 **DJI Mobile SDK V5(Android)**。Mini 4 Pro 从 **v5.13(2025-03)** 开始支持,当前最新为 5.18。(https://developer.dji.com/doc/mobile-sdk-tutorial/en/ ,https://dronedj.com/2025/03/21/dji-mini-4-pro-msdk/ ,核实 2026-10-02)
- **只支持 RC-N2 和 RC-N3,不支持带屏幕的 DJI RC 2**:RC 2 上不能装自己写的 App。(同上,核实 2026-10-02)
- 需要一台 **Android 手机**接在 RC-N2 上运行 App。iPhone 不行,属于推断,未专门核实 iOS 版 MSDK 对 Mini 4 Pro 的支持情况,见 ISSUES D-02。
- 要在 developer.dji.com 注册开发者,创建 App 拿到 App Key(和 Android 包名绑定)。
- 官方手册(JP)已下载到 `调研_DJI选购/Mini_4_Pro/`。

## 2. 法规框架(日本)

- 机重 ≥100g 必须**机体登记**(Mini 4 Pro 249g,内置 Remote ID)。
- **特定飞行**需要国交省许可:DID 上空、夜间、目视外、离人或物 30m 以内、活动现场上空、运输危险品、空投物品、机场周边、离地 150m 以上。
- 不属于特定飞行的,只要满足"白天 + 目视 + 离人车建筑 30m 以上 + 150m 以下"四个条件,就不需要国交省许可;但仍要遵守地方和管理者的规定,并取得土地所有者同意。
- 2025-12-05 起,**民间资格不能再用来简化许可申请**;二等资格 + 机体认证(型式认证机型)+ 禁止无关人员进入的措置三样都具备时,DID、夜间、目视外、30m 以内这几类可以免去许可申请。(https://shinkudrone.com/blog/ ,https://droneschool.kofuji.co.jp/drone-shinsei-menjo-nitou-2026/ ,核实 2026-10-02)
- 东京 23 区几乎全部是 DID;都立公园大多禁飞;重要设施周边约 300m 禁飞(小型无人机等飞行禁止法)。
- 国有林里飞:要向埼玉森林管理事务所提交「入林届」。(https://drone-nippon.jp/saitama/ ,核实 2026-10-02)

## 5. 飞行任务模板(相对坐标)

- 以起飞点 H 为原点,所有点用"方位角 + 距离 + 高度"定义;App 起飞时读取 H 的 GPS 坐标,再算出各点经纬度。**练习场版本的距离 ×0.5**,同一份代码直接复用。
- 主方向角 θ = 从 H 看向拍摄主体的方位,在现场用指南针测,然后输入 App。
- 上限:高度 ≤ 60m,离 H 的水平距离 ≤ 150m(保持目视)。

| 段 | 内容 | MSDK |
|---|---|---|
| M0 自检 | GPS 星数 ≥ 12、电量 ≥ 80%、风速告警、禁飞区、返航高度 50m;任何一项不过就拒绝起飞 | KeyManager、FlyZoneManager |
| M1 Rising Reveal | 5m 悬停 → 云台 −60° 抬到 0°,同时上升到 45m、后退 30m,4K 录像 | VirtualStickManager + 云台 / 相机 Key |
| M2 航点线 | 沿主体两侧(θ ± 90°)排 5 个点,间隔 25m,高度 40m,速度 4m/s,每点拍一张 48MP,云台 −25°,机头朝向主体 | WaypointMissionManager(KMZ / WPML);**Mini 4 Pro 是否支持待确认**,不支持就改用 VirtualStick |
| M3 环绕 | 以 θ 方向 80m 处为圆心,半径 30m,飞 3/4 圈,用时 90 秒,云台锁定圆心 | VirtualStick 10Hz 闭环 |
| M4 返回 | 回到 H 上空 10m → 降落 → 停止录像 | 返航 / 降落 Key |
| M5 日志 | 1Hz 记录时间、经纬度、高度、电量、云台角度,存成 CSV,导出到 Mac 分析 | KeyManager 监听 |

**实例:「長瀞 岩畳 Reveal」**:H 在岩畳对岸,远离游客;θ = 朝向岩畳;红叶季(11 月中下旬)的工作日早上。

## 6. 安全闸与飞行当天检查

- 写进代码的安全闸:电量 < 35% → 返航;离 H > 150m 或高度 > 60m → 中止任务、悬停、交手动;信号丢失 → 交给飞控返航;遥控器暂停键或摇杆一动 → 立即退出 VirtualStick;风速告警 → 跳过 M3。
- 风景区执行前:同一个 App、同一个任务(×0.5 距离)已经在练习场完整跑通至少 2 次。
- 飞行当天:用国土地理院地图确认 DID → DIPS 提交飞行计划 → 机体登记号和 Remote ID → 向管理方备案(长瀞:观光协会)→ 带上保险资料 → 拆装螺旋桨的检查。
- 拿到飞机的第一天:拆下螺旋桨,用 MSDK **模拟器**把 M0~M5 全跑一遍。

## 7. 买不买的判断标准

- 想长期写代码、经常调试 → 买。租一次约 1 万日元,租 3~4 次的钱就够买二手了。
- 只是偶尔拍风景 → 继续租;遥控器用 RC 2 就行,不需要 MSDK。
- 买的话要**机身 + RC-N2**。Mercari 上要找标明"RC-N2 付属"的;之前看过的 ¥88,500 那台只有 RC 2,不能编程。全新型式认证版 RC-N2 套装约 ¥90,750。(セキド、フジヤカメラ 等,核实 2026-10-02)
