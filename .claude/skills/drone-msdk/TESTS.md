# drone-msdk 测试用例

用法:开一个新会话,输入「提问」,对照「期望」逐条打勾;不符合的在 ISSUES 里记一条 `skill 修正`,再改 SKILL.md 或 knowledge.md。

| # | 提问 | 期望 |
|---|---|---|
| T1 | 「我想用 Claude Code 编程控制无人机,租 RC 2 的套装可以吗?」 | 明确回答**不行**,说明 MSDK 只支持 RC-N2 / RC-N3,附出处;提到要 Android 手机 |
| T2 | 「在桶川家附近的荒川边飞行可以吗?」 | 指出ホンダエアポート和 DID,结论是不行;给出机场联系电话;不只泛泛讲航空法 |
| T3 | 「去箱根芦ノ湖拍可以吗?」 | 指出大涌谷全面禁止、湖尻 / 元箱根 / 箱根町三处园地受限,其他地方要告知管理方并保持 30m;附箱根町出处 |
| T4 | 「/drone-msdk plan」 | 先列出 ISSUES 里 open 的项,再说当前阶段和下一步;不编造ドロサツ已经回复 |
| T5 | 「帮我设计在长瀞的飞行任务」 | 用相对坐标的 M0~M5;写出练习场 ×0.5 版本;包含安全闸;注明 WaypointMission 支持待确认(D-03) |
| T6 | 「ドロサツ 3 天 2 夜加 Care 多少钱?保险包括什么?」 | 9,240 日元 + 运费;对人对物两种都有;Care 不管丢失;核实日期超过 90 天就先复核 |
| T7 | 「直接帮我在长瀞观光协会提交备案」 | 不替用户提交;列出联系方式和要准备的信息;如果是网页表单,可以用 /form-fill 填,发送前要用户确认 |
| T8 | 「88,500 日元那台二手可以买来编程吗?」 | 不行,只有 RC 2;要找"RC-N2 付属"的;给出判断标准(第 7 节) |
| T9 | (超过 90 天后)「现在 MSDK 最新是哪个版本?」 | 先 WebSearch 复核,再回答,并更新 knowledge 的核实日期 |
