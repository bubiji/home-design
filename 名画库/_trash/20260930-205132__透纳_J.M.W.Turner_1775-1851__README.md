# 约瑟夫·马洛德·威廉·透纳(Joseph Mallord William Turner,1775–1851)

英国浪漫主义风景画家,以光、气象与海景著称,被视为印象派与抽象绘画的先驱。去世时将近 300 幅油画和约 3 万件素描、水彩遗赠英国国家(Turner Bequest),今多藏于泰特不列颠。2025 年为其诞辰 250 周年。
