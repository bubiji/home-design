# Mini 4 Pro × MSDK 飞行实验计划 v1

日期:2026-10-03
目的:用 Claude Code 写一个 DJI MSDK V5 的 Android App,控制 Mini 4 Pro 自动飞一段航线并拍摄,借此体验"AI 编程 → 真机验证"的完整流程;做完再决定买不买。
原则:**写代码不花租金;租期只用来验证;第一次跑自己写的代码,必须在练习场。**

## 2. 地点:桶川 / 北海道 / 箱根 怎么选

| 候选 | 法规与手续 | 适不适合本实验 |
|---|---|---|
| **桶川** | 车站周边是 DID(人口集中地区),要申请国交省许可;荒川河岸有 **ホンダエアポート**,官方写明"原则上请勿飞行",要飞必须事先联系(049-299-1111) | ❌ 家门口反而最不适合 |
| **北海道・美瑛** | **全町原则禁止**飞行;例外条件是:拿到国交省许可,并取得土地所有者同意,再向町役场申请(撮影前 1 周,商工観光交流課 0166-92-4321)。青い池要单独许可 | ❌ 手续最重,路也远;适合以后买了飞机再专门去 |
| **箱根** | **大涌谷全面禁止**;**湖尻園地、元箱根園地、箱根町園地**(芦ノ湖岸的热门地点)也受限制。其余地方只要符合航空法就不用另外申请,但要把"什么时候、在哪儿、为什么拍"告知相关管理方(船公司、箱根神社等),并和人、建筑保持 30m 以上 | △ 能飞,但好看的湖岸都受限、协调对象多;不适合第一次跑自己写的代码 |
| ⭐ **埼玉的无人机练习场**(如坂戸「そらのあそびば」,离桶川约 20km) | 场地本身就是不需要国交省许可的区域,不用办手续 | ✅ **第 1 次真机测试必须在这里**:没有路人,飞丢了或程序出 bug 损失最小 |
| ⭐ **长瀞(秩父)** 离桶川约 1 小时车程 | 大部分不是 DID;观光协会要求事先**备案**(0494-66-3311);据民间解说,荒川桥梁上空及周围 30m 禁飞(待核实);岩畳一带游客多,要保持 30m | ✅ **推荐的风景地**:近、手续轻、景色好(岩畳 + 荒川 + 11 月红叶) |

**结论:先在练习场把代码跑通(第 3 天上午),再去长瀞拍风景(第 3 天下午或另租一次)。** 箱根、美瑛留到买了飞机之后再去。

依据:[ホンダエアポート](https://honda-air.co.jp/news/company-news/461/)、[美瑛町](https://town.biei.hokkaido.jp/administration/administration/machizukuri/opinion/six/drone.html)、[箱根町 Q&A](https://www.town.hakone.kanagawa.jp/www/contents/1100000001192/index.html)、[长瀞观光协会](https://www.nagatoro.gr.jp/)、[そらのあそびば](https://www.soanosobiba.com/)

## 3. 飞行任务设计:「長瀞 岩畳 Reveal」

### 3.1 设计思路

- **所有航点都用相对坐标**:以起飞点 H 为原点,按"方位角 + 距离 + 高度"定义,App 在起飞时读取 H 的 GPS 坐标,再算出各点的经纬度。
  → **同一个任务可以原样先在练习场跑**(把距离缩小 50%),确认没问题再到长瀞跑。
- 起飞点 H 定在岩畳**对岸**(河的东侧)、远离游客的位置,具体在现场选。任务的主方向角 θ = 从 H 看向岩畳的方位,在现场用指南针测,然后输入 App。
- 高度不超过 60m,水平距离 H 不超过 150m,保证全程肉眼可见,不需要申请目视外飞行。

### 3.2 任务分段(全部由 App 自动执行,遥控器暂停键随时可以接管)

| 段 | 名称 | 动作 | 主要 MSDK 能力 |
|---|---|---|---|
| M0 | 起飞前自检 | GPS 星数 ≥ 12、电量 ≥ 80%、风速告警关闭、查询禁飞区、返航高度设为 50m、返航点设为 H;任何一项不过 → 拒绝起飞并说明原因 | `KeyManager`(FlightController / Battery 等 Key)、`FlyZoneManager` |
| M1 | Rising Reveal | 起飞到 5m 悬停 → 云台从 −60° 抬到 0°,同时上升到 45m、朝 θ 的反方向后退 30m,开始 4K 录像。岩畳和河面从画面底部"升"出来 | `VirtualStickManager`(按速度控制)+ 云台 Key + 相机录像 Key |
| M2 | 沿河航点线 | 5 个航点,沿河方向(θ ± 90°)排开,每点间隔 25m,高度 40m,速度 4m/s;每个航点拍一张 48MP 照片,云台 −25°,机头始终朝向岩畳 | `WaypointMissionManager`(由 App 生成 KMZ / WPML 航线文件再上传)。⚠️ Mini 4 Pro 是否支持该接口,第一步用模拟器确认;不支持就退回用 VirtualStick 自己实现 |
| M3 | 环绕兴趣点 | 以岩畳中心 P(在 θ 方向 80m 处)为圆心,半径 30m,飞 3/4 圈,用时 90 秒,云台锁定 P | `VirtualStickManager` 以 10Hz 发送"切向速度 + 偏航角速度",每次根据当前位置修正 |
| M4 | 返回降落 | 回到 H 上空 10m → 自动降落 → 停止录像 | 返航 / 降落 Key |
| M5 | 日志 | 全程按 1Hz 记录:时间、经纬度、高度、电量、云台角度,存成 CSV;降落后导出到 Mac,让 Claude Code 画轨迹图、做分析 | `KeyManager` 监听 → 写文件 |

### 3.3 安全闸(写进代码,不能只靠人)

- 电量 < 35% → 中止任务,立即返航。
- 离 H 的距离 > 150m 或高度 > 60m → 中止,悬停,交给手动。
- 遥控器信号丢失 → 交给飞控自带的返航(返航高度 50m,保证高于沿岸树木)。
- 遥控器暂停键或摇杆被拨动 → 立即退出 VirtualStick,交给手动。
- 风速告警出现 → 不执行 M3(环绕最吃风)。
- **长瀞执行前**:同一个 App、同一个任务(距离 × 0.5)已经在练习场完整跑通至少 2 次。

## 5. 买不买的判断标准(试完对照)

- 想**长期写代码**(经常调试) → 买。租一次约 1 万日元,试 3~4 次就够买二手了。
- 只是**偶尔拍风景** → 继续租,遥控器用 RC 2 就行,不需要 MSDK。
- 买的话:**机身 + RC-N2**(Mercari 上要找标明"RC-N2 付属"的;之前看的 ¥88,500 那台**只有 RC 2,不能编程**)。
