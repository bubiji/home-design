### 笔记体系(重点:数据全是本地 Markdown,Claude Code 可直接读写)

| 工具 | 定位 |
|------|------|
| **Obsidian** | 图形端主力:本质是"一个文件夹的 Markdown",Git 版本化,手机有官方 App |
| **nb** | 纯 CLI 全能笔记:笔记/书签/待办,自动 Git 提交,**可与 Obsidian 共用同一文件夹** |
| **jrnl** | 纯 CLI 日记:`jrnl 今天做了X` 一行记录,命令行查询 |
| zk | 纯 CLI 卡片盒(Zettelkasten)笔记,备选 |

三者不冲突:都是同一堆 Markdown 文件的不同入口。终端里用 nb/jrnl 快速记,Obsidian 里看和整理,Claude Code 负责检索、汇总、写周报。

## 四、反面清单(违反四原则,避开)

- **HP 打印机**:墨水订阅 + 耗材 DRM + 驱动全家桶
- **Sonos**:API 收紧,体验押在它的云和 App 上
- **Notion**(作为主力笔记):数据在云端,断网即残废;API 二等公民
- **Seagate BarraCuda 8TB (ST8000DM004)**:SMR 桌面盘,RAID 重建有风险(可接受的唯一用途:离线冷备份单盘)
- **Synology**:硬件贵配置缩水,DSM 封闭,"省心税"高(除非完全不想折腾)
