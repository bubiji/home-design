# home-design — 家里的折腾记录

画墙布置、名画库整理、装备调研、硬盘与照片迁移。2026-10-28 从家庭基础设施项目(私有、不公开)里拆出的可公开部分;路由器、设备登记簿、户型图纸等仍留在私有项目。

## 目录

| 目录 | 内容 |
|---|---|
| `名画库/` | 按「作者/技法/年份_作品」归档的名画资料(`资料.md`、manifests、日志)。**原图不入库**(2.3 GB),`资料.md` 里有馆方下载链接;`_logs/when_hd1_back.sh` 负责与外置盘同步 |
| `画墙/` | 客厅画墙:打印模板、名画素材、画墙预览页、参考书目、`脚本/gen_print_*.py`(A4 打印稿生成,含 ICC 转换)。`06_打印稿/` 成品(760 MB)不入库,由脚本重新生成 |
| `调研/` | 装备采购 2026Q4(显示器/扩展坞/硬盘)、DJI 选购(机型对比、MSDK 实验计划、二手行情)、新机选型、备选方案总表 |
| `硬盘与照片/` | 22T 硬盘检测教程、照片迁移方案 |
| `src/` | `art_fetch`(名画原图抓取)、`art_print`(打印)、`lyrics_ruby`(歌词注音 PDF)、`price_check`(比价) |
| `assets/` | 脚本用到的素材 |
| `.claude/skills/drone-msdk/` | DJI MSDK 知识卡 |

## 不在这里的东西

设备序列号、无人机登録記号、住址、户型图纸、网络配置一律不进本仓;调研里凡引用这类材料的地方只留「私密项目内」字样。
